### 核心优势

- **进程冷启动**：**5.80 ms** vs 原版 V8 **36.74 ms**（启动提速 **6.3x**，启动延迟降低 **84.2%**）
- **综合得分**：**110** vs 原版 V8 **65,139**（-99.8%）
- **二进制体积**：**2.3 MB** vs 原版 V8 **32.0 MB**（体积缩减 **92.8%**）
