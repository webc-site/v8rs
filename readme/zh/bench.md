### 核心优势

- **进程冷启动**：**5.70 ms** vs 原版 V8 **33.64 ms**（启动提速 **5.9x**，启动延迟降低 **83.1%**）
- **综合得分**：**78** vs 原版 V8 **65,605**（-99.9%）
- **二进制体积**：**1.9 MB** vs 原版 V8 **32.0 MB**（体积缩减 **94.1%**）
