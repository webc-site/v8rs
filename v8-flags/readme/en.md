# v8-flags

Rust port of `v8/src/flags` — the V8 flag system (998 primary flags, canonical config macOS arm64 release). See [中文](#zh) for the full module/test mapping.

## Mapping (see zh.md for full tables)

- flag-definitions.h → src/defs.rs + src/implications_gen.rs + src/contradictions_gen.rs + src/features_gen.rs + src/counts.rs (generated by tool/src/flags/flag-definitions.h.js)
- flags.h → src/value.rs; flags-impl.h → src/lookup.rs; flags.cc → src/flags.rs + src/save.rs + src/base.rs
- feature-flags.h → src/features.rs; save-flags.h/.cc → src/save.rs

## Count gate (three-way)

Generated tables == counts.rs constants == tool/src/flags/stats.json, checked at
compile time (const asserts in lib.rs) and in tests/main.rs::counts_consistency:
998 primary / 1 alias / 119 readonly / 847 implications (830 value + 5 warn +
6 generic + 6 require) / 34 features / 80 contradictions.

## Documented deviations

- Error path is `Result`-based (C++ returns failing argv index / aborts); argv is
  not shrunk on error; parsed changes are not rolled back (same as C++ comment).
- Freeze is API-level only (page protection deferred).
- Flag-list hash uses a self-consistent FNV-1a kernel (value need not match C++).
- float display uses Rust's native shortest round-trip formatting.

## Deferred

Page protection for FreezeFlags; --help / --print-feature-flags-json output and
exit side effects (shell layer); HelpOptions; fuzztest domain-randomized variant
(representative samples instead); TracingFlags relocation to v8-logging;
DEBUG-only predictable-flag verification.
