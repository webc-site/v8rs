# v8-numbers (English summary)

Rust port of `v8/src/numbers` (~2.9k lines): the Number↔String family
(ECMAScript semantic redline layer), parseInt/parseFloat, the Math.random
state machine, hash-seed data plane, ieee754 pow, and IntegerLiteral.

## Mapping (see zh.md for full tables)

- conversions.{h,cc,-inl.h} → src/conversions/{mod,simple_builder,parse_int,
  parse_double,to_string,special_index,tables}.rs (tables.rs generated by
  tool/src/numbers/conversions.cc.js)
- hash-seed → src/hash_seed.rs (RAPIDHASH_DEFAULT_SECRET extracted by script)
- ieee754 / integer-literal / math-random → same-named modules

## Semantic redlines (todo 10.3)

- Number.prototype.toString format layer (21-digit / 1e-7 thresholds,
  e±XX exponent switch) is hand-written; shortest-decimal kernel = zmij
  (Schubfach), 100% match on the 100k-entry gay-shortest golden corpus.
- parseInt/parseFloat scanning layer hand-written; decimal rounding kernel =
  v8-base strtod (bignum fallback); 2^n radix paths 1:1 ported.
- Math.random: XorShift128+ / MurmurHash3 / ToDouble 1:1, differentially
  verified against an independent bun reimplementation.
