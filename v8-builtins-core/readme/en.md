# v8-builtins-core

V8 Builtins core metadata and dispatch table definitions.

## Architecture

1. **Aggregation Pipeline**:
   - Generated by `tool/src/builtins/builtins-core.js` from 25 source files in `v8/src/builtins/`;
   - Active modules:
     - `kind.rs`: `BuiltinKind` enum (CPP, TFJ_TSA, TFJ, TFC_TSA, TFC, TFS, TFH, ASM, BCH) and classification methods (`is_cpp`, `has_js_linkage`, `is_code_stub`, `is_asm`, `is_bytecode_handler`);
     - `table.rs`: `BUILTIN_TABLE` 1111 entries, `BUILTIN_TABLE_LEN`, `is_tier0`, lookup helpers (`get_builtin`, `find_builtin`, `count_by_kind`);
     - `descriptors.rs`: `descriptor_name` interface descriptor symbol generator;
     - `infra.rs`: `TQ_INFRA_DECLS` 607 Torque infrastructure declarations;
     - `error.rs`: Typed lookup errors.
2. **Baseline Notes**:
   - `builtins_definitions.rs`, `builtins_descriptors.rs`, `setup_builtins_internal.rs` are legacy single-file extraction files fully superseded by the aggregate `builtins-core.js` pipeline.
